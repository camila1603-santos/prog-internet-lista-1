Códigos de estado HTTP

Toda resposta de um servidor web traz um código de estado (status code): um número de três dígitos que informa ao navegador o resultado da requisição. O primeiro dígito indica a categoria da resposta.

Categorias

As cinco classes de códigos de estado
Classe Significado Exemplo
1xx Informação 100 Continue
2xx Sucesso 200 OK
3xx Redirecionamento 301 Moved Permanently
4xx Erro do cliente 404 Not Found
5xx Erro do servidor 500 Internal Server Error

Códigos mais comuns

  • 200 OK: a página foi entregue normalmente.
  • 201 Created: um novo recurso foi criado, por exemplo após enviar um cadastro.
  • 301 Moved Permanently: o endereço mudou de forma definitiva.
  • 304 Not Modified: o recurso não mudou, então o navegador usa a cópia em cache.
  • 401 Unauthorized: é preciso fazer login para acessar.
  • 403 Forbidden: o acesso é proibido mesmo com login.
  • 404 Not Found: a página não existe.
  • 500 Internal Server Error: houve um erro no servidor.
  • 503 Service Unavailable: o servidor está fora do ar ou sobrecarregado.

Para entender como os códigos aparecem dentro de uma resposta, veja a página HTTP.
