Diferença entre Internet e Web

A Internet é a rede mundial que conecta computadores e permite a troca de dados entre eles. A Web é um dos serviços que funcionam sobre a Internet: um conjunto de páginas ligadas por links e acessadas pelo navegador usando o protocolo HTTP.
